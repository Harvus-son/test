# Moodly

Многостраничный интерактивный сайт для отслеживания настроения.

## Страницы
- `index.html` — главная и краткая статистика
- `mood.html` — интерактивный check-in
- `diary.html` — история записей
- `insights.html` — график и простые инсайты

## Технологии
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- GitHub Pages

Записи не отправляются на сервер: приложение хранит их локально в браузере пользователя.
